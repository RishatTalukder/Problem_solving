# Maximum K to Sort a Permutation Using Bitwise AND

## Intuition

The key observation is that **we only need to consider the elements that are already in the wrong positions**.

The array is a permutation of the numbers from `0` to `n - 1`, so the sorted array must be:

```text
[0, 1, 2, 3, ..., n - 1]
```

If an element `v` is currently at index `i`, but `i != v`, that element must move somewhere else to sort the array.

Now, remember the condition for swapping two elements:

\[
a \mathbin{\&} b = k
\]

The bitwise AND of two numbers keeps only the bits that are set to `1` in **both** numbers.

For example:

```text
3 = 011
1 = 001
    ---
AND 001 = 1
```

Therefore, `3` and `1` can be swapped when `k = 1`.

### Why does the answer involve the AND of misplaced elements?

Suppose an element `v` is in the wrong position. To move it, it must participate in at least one valid swap.

For any swap involving `v`, the condition requires:

\[
v \mathbin{\&} x = k
\]

This means every bit set in `k` must also be set in `v`. In other words, `k` must be a bitwise submask of every element that needs to move.

If we want the largest possible `k`, we should preserve every bit that is common to all misplaced elements.

That is exactly what repeatedly applying bitwise AND does.

For example, consider:

```text
nums = [0, 3, 2, 1]
```

The elements at indices `1` and `3` are misplaced:

```text
Index:  0  1  2  3
Value:  0  3  2  1
```

Their bitwise AND is:

```text
3 = 011
1 = 001
    ---
    001 = 1
```

So the largest possible `k` is `1`.

With `k = 1`, we can swap `3` and `1`, because their AND is `1`. The array becomes sorted:

```text
[0, 1, 2, 3]
```

### Why can we AND all misplaced elements together?

Let \(M\) be the set of values that are not at their correct indices.

Any element in \(M\) must move. Since an element can only be swapped when its AND with the other element equals `k`, every bit set in `k` must be present in every misplaced element.

Therefore:

\[
k \subseteq \bigcap_{v \in M}\text{bits}(v)
\]

The bitwise AND of all misplaced elements gives precisely the common set bits:

\[
K = \bigwedge_{v \in M} v
\]

Every valid `k` must be a submask of \(K\), so no valid `k` can be numerically larger than \(K\).

The remaining question is whether this maximum candidate actually allows sorting.

For every misplaced element, all its bits that are set in \(K\) are also set in that element. Thus, its AND with \(K\) equals \(K\). Any two misplaced elements can therefore be swapped under this value of `k`.

Since the misplaced elements can be freely swapped with one another, we can arrange them into their correct positions. Elements already in their correct positions do not need to move.

Hence, the AND of all misplaced elements is not just an upper bound: it is achievable, making it the maximum possible answer.

### What if the array is already sorted?

If every element is already at its correct index, there are no misplaced elements to constrain `k`.

The problem explicitly requires returning `0` in this case.

Our running AND starts at `-1`, whose binary representation in Python behaves like an all-ones mask for bitwise operations. If no misplaced element is found, the value remains `-1`, which we use to detect this special case.

## Approach

1. Initialize `k = -1`, which acts as an all-ones bitmask for the AND operations.
2. Iterate through the array, comparing each element `v` with its index `i`.
3. If `i != v`, the element is misplaced. Update `k` using `k &= v`, retaining only the bits common to all misplaced elements.
4. After processing the array, if `k` is still `-1`, the array was already sorted, so return `0`.
5. Otherwise, return `k`, which is the maximum value that allows the array to be sorted.

## Complexity

- **Time complexity:** \(O(n)\), because we examine each element exactly once and perform constant-time operations.
- **Space complexity:** \(O(1)\), because we use only a constant number of variables.

## Code

```python3
class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        k = -1

        for i, v in enumerate(nums):
            if i != v:
                k &= v

        return 0 if k == -1 else k
```
